# 우니드 홈페이지

우니드의 비전과 개발 중인 AI 콘텐츠 점검 서비스 Creadar를 소개하는 반응형 회사 홈페이지입니다. 외부 패키지 없이 HTML, CSS, JavaScript로 구성했습니다.

## 실행

Node.js 18 이상에서 `npm run dev`를 실행하고 http://localhost:3000 에 접속합니다. `PORT` 환경변수로 포트를 변경할 수 있습니다.

## 배포용 빌드

`npm run build`를 실행하면 `dist/`에 정적 파일이 생성됩니다. 정적 웹 호스팅 서비스에 해당 폴더를 배포할 수 있습니다.

## 공개 전 확인

- `script.js` 상단 `company`에 실제 문의 이메일과 사업자명, 대표자, 사업자등록번호를 입력합니다. 빈 값은 노출하지 않으며, 연락처 미입력 시 문의 채널 준비 중으로 표시합니다.
- Creadar의 현재 단계는 사용자 확인에 따라 ‘개발 중’으로 표시했습니다.
- 서비스 화면은 설명을 위한 인터랙티브 예시입니다. 실제 영상 업로드나 AI 분석은 수행하지 않습니다.
- 회사 소개 문단은 제공된 사업 방향을 바탕으로 작성한 초안입니다. 실제 창업 배경과 일치하는지 공개 전에 검토해 주세요.
- 현재 개인정보를 수집하거나 외부 분석·추적 도구를 사용하지 않습니다. 사전 신청 폼 등을 도입할 경우 실제 처리 방식에 맞는 수집 안내와 개인정보 처리방침을 함께 준비해야 합니다.
- 보안, 보관 기간, 학습 사용 여부 등에 대한 미확인 약속은 포함하지 않았습니다.
